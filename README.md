# Sunhow · 地藏菩萨本愿经注解

[在线阅读](https://sunhow.github.io/dizang-reader/)

一部可以慢慢读、随手记的经。纸色、朱红与简洁莲花线稿，沿用个人精读网站的风格。

## 内容与功能

- 通行三卷十三品正文，153 个自然段，每段独立标题、完整白话译文及可展开的阅读提示。
- 130 个佛教及文言词条；逐段模式只显示当前段落涉及的词语。
- 品导读、逐段精读、通篇对照、全文检索、浏览器朗读。
- 简体／来源繁体经文切换，纸白／米黄／夜读，字号、横竖排。
- 每品笔记、阅读位置、完成标记与 JSON 备份导入导出。
- 纯静态、无后端、无第三方运行时依赖，支持手机及首次完整加载后的离线阅读。

白话逐句展开原文意思，保留人物问答、数字与清单；原有注解单独作为阅读提示。译文与提示为 AI 辅助学习稿，尚未经过佛教学者或法师逐条审定。正文范围、来源、对照边界及授权见 [SOURCES.md](SOURCES.md)。

## 本地运行与维护

需要 Python 3.9+，无需安装包：

```sh
python3 build_site.py
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:4174/`。

- `config.js`：个人署名和网站文案。
- `sutra-source.json`：十三品经文、段落标题、完整白话译文、阅读提示与来源。
- `glossary.json`：名词注解。
- `build.py`：检查十三品、153 段对应和来源哈希，生成 `book.js`。
- `build_site.py`：构建 `dist/`，按资源内容更新离线缓存版本。

内容修改后运行构建，把 `book.js`、`sw.js` 及所改源码一并提交。若确需订正繁体底本，先核对来源，记录订正理由，再更新该段 `sourceHash`，不要仅为绕过检查重算。

## GitHub Pages

仓库根目录直接包含可发布文件。Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save。每次提交发布文件会自动更新；无需自定义 Actions 工作流。`dist/` 不必提交。

所有资源使用相对路径，和易经站、原有个人博客分别部署。

## 笔记与进度

数据只保存在当前浏览器，键名前缀为 `dizang.`，不会自动上传到 GitHub，也不与易经站混用。换设备或清理浏览器前，可在设置中导出 JSON 备份；导入时按每品修改时间保留较新记录。无法导入易经站的备份，以免误覆盖。

语音朗读依赖浏览器及设备的中文语音，效果和离线可用性因系统而异。
